## 🚀 Featured Project

# 👗 Smart Wardrobe App

A wardrobe management and outfit recommendation application designed to help users organize their clothing, plan outfits, and discover outfit inspiration.

**This project includes two implementations:**

### 🐍 1. Python & Streamlit Version

Built using Python, Streamlit, and SQLite.

**Features:**
- Add and manage clothing items with photos.
- Organize clothes by category.
- Generate outfit suggestions for different occasions.
- Plan and save outfits.
- Save favorite clothing items.
- Explore live weather-based clothing suggestions.

**Technologies:** Python, Streamlit, SQLite, OpenWeather API.

### 📱 2. Flutter Version

A Flutter-based version of Smart Wardrobe with a user-friendly interface.

**Technologies:** Flutter, Dart, OpenWeather API.

**Project structure:**
- `smart_wardrobe_flutter/` – Flutter application source code.
- `app.py` – Python application.
- `database.py` – SQLite database operations.
